# 微信读书 · VS Code 安全入口

在 VS Code 中提供微信读书官方网页的快捷入口。登录、书架、阅读和进度同步全部在系统默认浏览器中的微信读书官方页面完成。

## 安全模式

- 不在 VS Code 中嵌入或修改微信读书网页
- 不启动本地反向代理
- 不读取、传输或保存登录 Cookie
- 不下载、解密、导出或重新分发书籍正文
- 只允许打开 `https://weread.qq.com` 官方域名

这样可以避免第三方修改浏览器或客户端的风险提示。插件无法读取官方浏览器中的登录状态和阅读进度；同步仍由微信读书官方网页及手机 App 完成。

从旧版升级时，扩展会删除此前由代理模式保存在 VS Code SecretStorage 中的微信读书登录会话。

## 功能

- 资源管理器下方提供“文档预览”快捷面板
- 一键打开微信读书官方首页
- 一键打开官方书架
- 可展开为编辑器标签页查看安全模式说明
- 状态栏图标快捷入口
- 网络与安全模式自检
- 老板键隐藏或恢复 VS Code 内的入口面板

## 使用

1. 安装生成的 `.vsix`。
2. 重新加载 VS Code 窗口。
3. 点击状态栏书本图标，或运行 `微信读书：打开安全入口`。
4. 点击“打开微信读书”或“打开官方书架”。
5. 在系统默认浏览器的官方网页中登录和阅读。

## 老板键

- Windows / Linux：`Ctrl+Alt+B`
- macOS：`Cmd+Alt+B`

老板键只隐藏或恢复 VS Code 内的入口面板，不会控制系统浏览器窗口。

## 本地开发

