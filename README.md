# 微信读书 · VS Code 阅读器

在 VS Code 标签页中打开微信读书官方 Web 阅读器。扫码登录后，书架、阅读进度、划线和笔记均由微信读书账号自动同步。

## 已实现

- 在编辑器标签页内打开微信读书
- 微信扫码登录与个人书架
- 阅读、翻页、目录、字体和主题等官方网页能力
- 阅读进度、书架、划线和笔记的账号同步
- 标签页内书架、刷新、浏览器打开快捷按钮
- 状态栏快捷入口
- 本地开发、Remote SSH、WSL 和 Codespaces 端口映射支持
- 自动选择空闲本地端口，也可手动指定

## 使用

1. 安装生成的 `.vsix`。
2. 打开命令面板，运行 `微信读书：打开阅读器`；也可以点击右下角状态栏的“微信读书”。
3. 在标签页中扫码登录，进入个人书架后开始阅读。
4. 正常退出书籍或关闭标签页即可；阅读进度由微信读书网页自动上报。

## 本地开发

```bash
npm install
npm run check
```

在 VS Code 中按 `F5` 可启动扩展开发宿主。

打包安装文件：

```bash
npm run package
```

## 工作方式与边界

扩展只在本机 `127.0.0.1` 启动一个临时、受限的反向代理，将微信读书官方网页嵌入 VS Code。代理关闭后端口立即释放；账号会话保存在 VS Code Webview 的站点存储中，扩展不会把 Cookie 写入项目文件。

同步依赖微信读书官方网页与账号服务。由于这不是微信读书官方扩展，微信读书网页结构或安全策略更新后，嵌入能力可能需要跟随适配。部分登录跳转、付费、听书或分组交互如果在内嵌页中受限，可点击“浏览器打开”继续使用官方网页。

本项目不下载、解密、导出或重新分发书籍正文。

## 隐私

- 网络请求仅代理至 `https://weread.qq.com`
- 本地服务只监听 `127.0.0.1`
- 不采集遥测，不上传额外数据
- 不在项目目录或配置文件中存储账号凭据
