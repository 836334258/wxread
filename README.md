# 微信读书 · VS Code 阅读器

在 VS Code 资源管理器小窗或编辑器标签页中打开微信读书官方 Web 阅读器。扫码登录后，书架、阅读进度、划线和笔记均由微信读书账号自动同步。

## 已实现

- 在资源管理器下方的小窗中阅读，可拖动侧栏边缘与视图分隔线调整宽高
- 可一键展开到编辑器区域阅读
- 微信扫码登录与个人书架
- 阅读、翻页、目录、字体和主题等官方网页能力
- 阅读进度、书架、划线和笔记的账号同步
- 使用 VS Code SecretStorage 安全保持登录会话
- 自动记录最后一本书，并提供“继续阅读”
- 状态栏显示登录、同步中、同步成功与异常状态
- 网络异常自动重试两次，并提供手工恢复入口
- 登录与同步自检助手
- 老板键快速隐藏和恢复阅读器
- 标签页内书架、刷新、浏览器打开快捷按钮
- 状态栏快捷入口
- 本地开发、Remote SSH、WSL 和 Codespaces 端口映射支持
- 自动选择空闲本地端口，也可手动指定

## 使用

1. 安装生成的 `.vsix`。
2. 点击右下角微信读书图标，或运行 `微信读书：打开阅读小窗`。
3. 小窗默认位于资源管理器下方。拖动左侧栏右边缘调整宽度，拖动“微信读书”标题上方的分隔线调整高度。
4. 在小窗中扫码登录后开始阅读；需要更大空间时点击“展开”。
5. 正常退出书籍或关闭阅读页即可；阅读进度由微信读书网页自动上报。

## 老板键

- Windows / Linux：`Ctrl+Alt+B`
- macOS：`Cmd+Alt+B`

阅读器显示时按下老板键，会立即切回之前的代码文件，但保留阅读页面和登录状态；再次按下可恢复阅读器。快捷键可在 VS Code 的“键盘快捷方式”中自行修改。

## 同步自检

打开命令面板，运行 `微信读书：运行登录与同步自检`。扩展会检查：

- 微信读书官网是否可访问
- 登录会话是否已安全保存
- 是否记录到最近阅读书籍
- 是否捕获到最近一次成功的进度或划线同步

手机 App 是否显示相同进度仍需人工确认：在 VS Code 中翻页后，打开微信读书 App 查看同一本书的进度。

## 本地开发

```bash

```

在 VS Code 中按 `F5` 可启动扩展开发宿主。

打包安装文件：

```bash
npm run package
```

## 工作方式与边界

扩展只在本机 `127.0.0.1` 启动一个临时、受限的反向代理，将微信读书官方网页嵌入 VS Code。代理关闭后端口立即释放；账号会话使用 VS Code SecretStorage 加密存储，扩展不会把 Cookie 写入项目文件或普通配置。

同步依赖微信读书官方网页与账号服务。由于这不是微信读书官方扩展，微信读书网页结构或安全策略更新后，嵌入能力可能需要跟随适配。部分登录跳转、付费、听书或分组交互如果在内嵌页中受限，可点击“浏览器打开”继续使用官方网页。

本项目不下载、解密、导出或重新分发书籍正文。

## 隐私

- 网络请求仅代理至 `https://weread.qq.com`
- 本地服务只监听 `127.0.0.1`
- 不采集遥测，不上传额外数据
- 登录 Cookie 仅保存在 VS Code SecretStorage，不进入项目目录或普通配置文件
